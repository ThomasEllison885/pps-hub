# Competitor logos (private builds only)

PNG marks for major US carriers used in Route Lab’s league scoreboard and rival panels.

**Private default:** real logos on (`ROUTELAB_REAL_LOGOS=1` or unset).

**Public release:** set `ROUTELAB_REAL_LOGOS=0` and switch airline display names to near-names. The UI falls back to stylized SVG marks when `logo` paths are stripped.

Sources: public site icons (favicon / app icons) for private internal use. Do not redistribute as a public product with real marks without rights clearance.
