# PSC Training — Proposal Generator Craft (shipped)

**Status:** Implemented in `psc_training_data.py` (July 2026).  
**Through-line:** The Pure Way — Trust · Quality · Results (judgment, not slogan spam).

## What shipped

1. **Core values — Pure Way section** (`cv_pure_way`)  
   Behavioral map: trust / commercial quality / results; activities for one job, quality bar, breach replacements.

2. **Company Operations module — Proposal Generator Craft** (`ops_proposal_generator`, Week 1+)  
   12 trackable items: Old vs New, form map, short vs full, issue→outcome, production-ready scope notes, site observations, pricing modes, full practice generate, Comparison habit, PM handoff test, live review, Pure Way check.

3. **Sales Training — Proposal as Sales Tool** expanded  
   Generator-first, investment language, never cold-send, earn-trust→CapEx, Comparison required before independent proposals.

4. **Weeks 0–4 focus** retargeted  
   Pure Way in Week 0; craft steps through apartment segment with paint/roof/gutter field practice.

5. **Meta description** updated to center proposal craft + Pure Way.

## Success criteria (graduation gate for proposals)

A trainee is not cleared for independent client proposals until:

- [ ] Pure Way map + commercial quality bar activities done  
- [ ] Full practice proposal generated and production-ready test passed with PM/manager  
- [ ] One Proposal Comparison submitted  
- [ ] Live review conversation role-played  
- [ ] Manager confirms generator is default (not freeform Word)  

## Pure Way in this module

| Pillar | Craft behavior |
|--------|----------------|
| Trust | Honest includes/excludes; no invented site findings; no cold-send; no phantom dates |
| Quality | Commercial standard language; product/systems named when known; punch/invoice culture |
| Results | Clear investment; options that close; small scopes that earn CapEx |
